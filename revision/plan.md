# 改訂スケジュール（2026年9月〜2027年2月）

## ゴール

GopherCon Japan 2027 に合わせて改訂を進めます。

- 開催：2027年2月13日（土）・14日（日）、Abema Towers（[connpass](https://gopherconjp.connpass.com/event/407167/)）
- CfP：[Sessionize](https://sessionize.com/gopherconjp-2027/)、締め切りは10月下旬（正確な日時は要確認）

段階は2つです。

1. **CfP版（〜10月下旬）**：プロポーザルに添えるURLとして、「最新の Go に追従しつつある」ことが見て取れる状態で公開する。重要なトピックを1〜2個カバーしていれば十分。
2. **本番版（〜2027年1月末）**：改訂範囲の8割程度を更新する。2月前半は発表準備に充てるため、本の作業は1月末で凍結する。

## CfP版の定義

時間が約4週間しかないので、次の条件を満たせば完成とします。

- 改訂版として公開されている（GitHub Pages）。冒頭に「改訂中」の告知と対象バージョン（Go 1.27）が書いてある
- 誤った説明（ジェネリクスがない、GOPATH から .a を読む、など）や廃止されたツール（gddo, guru）の節が本文から消えている。WIP の章は目次から外してある
- サンプルが Go 1.27 で動き、CI で確かめられている
- 次の2トピックが現代化されている

  **トピック1：構文解析章の現代化。** ジェネリクス関連の構文ノード（A-05）、Preorder などを含む構文木の走査（A-02）、ast.Object の縮小と非推奨化（A-10, A-04）。既存の章に手を入れるので分量の見積もりが立てやすく、「追従している」ことが一目で伝わる。

  **トピック2：go/analysis 入門（新章の最初の一節）。** Analyzer と Pass で最小の linter を書き、analysistest でテストするところまで（N-01, N-06）。旧版になかった内容なので、改訂の方向を示せる。プロポーザルの主題の候補にもなる。

inspector と Cursor（N-03）、Requires による依存関係（N-02）は、時間が余れば入れる扱いにして、正式には M1 に置いています。

## 伴走のしかた

CfP の締め切りまでは毎週（月曜の朝）、その後は隔週（毎月1日と15日の朝）に編集チェックインを行います。その時点までのコミットとスプレッドシートのステータスを見て、次のことを短く返します。

- 前回からの進み具合（マイルストーンに対して予定どおりか）
- 新しく書かれた原稿への編集コメント（構成・説明の順序・技術的な正確さ・読者がつまずきそうな箇所。原稿は書き換えず、指摘だけする）
- 次にやると良いこと
- Go や x/tools のリリースで本書に影響する変更があれば、その知らせ
